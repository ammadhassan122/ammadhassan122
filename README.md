## About

I'm a Computer Science student at the University of South Asia, Lahore (2023–2027), specializing in full-stack web development with 1 year of practical remote industry and freelance experience. 

I build robust, production-ready web applications using **React, Next.js, Tailwind CSS, Node.js, and MongoDB**, paired with modern Backend-as-a-Service tools like **Appwrite, Firebase, and Supabase**. I deploy scalable applications efficiently on Vercel and Hostinger cloud infrastructure to guarantee high-performance user experiences.
